# cadastro-simples-clinica-veterinaria

-> Cadastro de pacientes de uma clínica veterinária

DADOS

* Informações Animal

- Espécie
- Nome
- Idade
- Sexo  (F fêmea ou M macho)
- Raça
- Peso
- Altura
- Castrado (true ou false)

* Informações Dono

- Nome dono
- Idade dono
- Telefone dono

* Opcionais

- Porte
- Cor
- Pelagem
