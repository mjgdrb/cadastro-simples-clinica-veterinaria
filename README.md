# cadastro-cadastro-clinica-veterinaria

INFORMAÇÕES DO PROJETO

-> Cadastro de pacientes de uma clínica veterinária

-> Linguagem C

-> Struct, CSV, Diferentes SO

DADOS

* Informações Animal

  - Espécie
  - Nome
  - Idade
  - Sexo  /fêmea ou macho
  - Raça
  - Peso
  - Castrado /castrado ou nao castrado

* Informações Dono

  - Nome dono
  - Telefone dono

OPÇÕES
  
  1 - Cadastrar Paciente
  2 - Atualizar Cadastro
  3 - Imprimir Todos os Cadastros
  4 - Pesquisar Paciente
  5 - Apagar Cadastro
  0 - Sair
